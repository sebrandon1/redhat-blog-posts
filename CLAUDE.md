# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

A collection of Red Hat engineering blog posts organized by topic. Posts are written in Markdown and indexed in README.md.

## Structure

- `README.md` — Index of all posts organized by category with date, title, and link
- `posts/` — Individual blog post Markdown files

## Adding a New Post

1. Write the post in `posts/<slug>.md`
2. Add an entry to the appropriate category table in `README.md` (sorted by date, newest first)
